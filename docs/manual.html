Mode 0

Detection

ตรวจจับและนับวัตถุใน ROI — รองรับทั้ง Stop & Capture และ Continuous

🚀 วิธีใช้งาน
1
ตั้ง ROI ให้ครอบคลุมพื้นที่ที่วัตถุจะปรากฏ
2
เลือก Counting Method — Stop & Capture (กดเองทุกครั้ง) หรือ Continuous (อัตโนมัติเมื่อข้ามเส้น)
3
กด START — ระบบวิเคราะห์ทุก frame
4
กรอบ สีเขียว = พบวัตถุ  |  กรอบ สีส้ม = ไม่พบวัตถุ
🔧 Algorithm Parameters
ParameterDefaultRangeคำอธิบาย
Binary Thresh 127 0–255 ค่าแยกวัตถุออกจากพื้นหลัง — ลดสำหรับ dark object, เพิ่มสำหรับ light object
Min Area 500 10–100,000 ขนาดพิกเซลขั้นต่ำ — เพิ่มเพื่อกรอง noise รอบข้าง
Max Area 50,000 10–100,000 ขนาดพิกเซลสูงสุด — ลดเพื่อกรองวัตถุขนาดใหญ่ออก

Mode 1

Defect Inspection

ตรวจหาของเสียเทียบกับ master piece — รูปร่าง, สี, พื้นผิว

🚀 วิธีใช้งาน
1
วาง ชิ้นงานที่ดี (master piece) ใน ROI
2
กด CHANGE TEMPLATE (MASTER PIECE) ใน Admin Settings เพื่อบันทึก master
3
วางชิ้นงานที่ต้องการตรวจสอบใน ROI แล้วกด CAPTURE IMAGE
4
กรอบ สีเขียว = PASS  |  กรอบ สีแดง = DEFECT พร้อมกล่องสีส้มระบุตำแหน่ง
🔒 โหมดนี้ใช้ Stop & Capture เท่านั้น — Continuous ถูก lock ไว้
🔧 Algorithm Parameters
ParameterDefaultRangeคำอธิบาย
Minimum Match (%) 80 40–99 ความคล้ายรูปร่างขั้นต่ำกับ master — ลดลงถ้า false fail เยอะ
Color Tolerance 28 1–100 ยอมรับสีต่างจาก master ได้เท่าไร — เพิ่มถ้า lighting ไม่สม่ำเสมอ
Min Defect Area 25 1–5,000 ขนาดพิกเซลขั้นต่ำของ defect — เพิ่มเพื่อกรอง noise เล็กๆ ออก
Fixture Tolerance (px) 0 0–30 ยอมให้ชิ้นงานเยื้องจาก master ได้กี่พิกเซล — เพิ่มถ้าวางไม่ตรง jig เป๊ะ
📊 ผลลัพธ์
PASS (OK)
DEFECT SHAPE (NG)
DEFECT COLOR (NG)
NO TEMPLATE SET
ROI SIZE CHANGED

M:97.4% C:12.3
💡 ระบบใช้ทั้ง Template Matching + ML Patch Anomaly Detection ร่วมกัน — จับ defect ได้แม้แต่รอยขีดข่วนที่ subtle
🛠️ Troubleshooting
ปัญหาวิธีแก้
DEFECT ทั้งที่งานดีลด Minimum Match % หรือเพิ่ม Color Tolerance
ไม่จับ defect เล็กๆลด Min Defect Area
สั่น/เยื้องแล้วขึ้น DEFECTเพิ่ม Fixture Tolerance
ROI SIZE CHANGED ขึ้นกด CHANGE TEMPLATE ใหม่หลังเปลี่ยน ROI

Mode 2

Classification

แยกประเภทวัตถุตามสี รูปร่าง และขนาดอัตโนมัติ

🚀 วิธีใช้งาน
1
เลือกสีที่ต้องการจับ — ติ๊ก Detect All Colors หรือเลือกเฉพาะสีที่ต้องการ
2
กด START — ระบบจะแยกประเภทวัตถุแต่ละชิ้นใน ROI ทุก frame
3
ผลจะแสดงชื่อสีและขนาดของแต่ละ object บนภาพ
🔧 Algorithm Parameters
ParameterDefaultRangeคำอธิบาย
Detect All Colors เปิด on/off ตรวจจับทุกสี — ปิดเพื่อเลือกสีเฉพาะ
Red / Pink / Purple
Blue / Green / Brown		 ทั้งหมด on/off เปิดใช้เมื่อปิด All Colors — เลือกได้รายสี
Min Area 350 50–20,000 ขนาดพิกเซลขั้นต่ำ — เพิ่มเพื่อกรอง noise สี
Hue Margin 0 0–20 ขยาย range ของแต่ละสี — เพิ่มถ้าสีของงานแปรผัน

Mode 3

Code Reading

อ่าน QR Code, Barcode (1D), DataMatrix — รองรับหลาย backend อัตโนมัติ

🚀 วิธีใช้งาน
1
ชี้ ROI ไปที่บริเวณที่มี code
2
กด START — ระบบอ่านและแสดงค่าอัตโนมัติ
3
(Optional) กรอก Expected Code เพื่อ verify ว่าค่าที่อ่านได้ตรงกับที่คาดไว้หรือไม่
🔧 Algorithm Parameters
Parameterคำอธิบาย
Supported Types Barcode / QR / DataMatrix — รองรับทั้งหมดอัตโนมัติ ไม่ต้องตั้งค่า
Expected Code ถ้ากรอกค่า ระบบจะเปรียบเทียบและขึ้น FAIL = Code Mismatch ถ้าไม่ตรง — เว้นว่างเพื่อรับทุกค่า
💡 Backend ที่ใช้ (อัตโนมัติ): OpenCV QR, OpenCV Barcode, pyzbar (ถ้าติดตั้ง), pylibdmtx (ถ้าติดตั้ง) — ใช้ทุกตัวที่มีพร้อมกัน

Mode 4

Counting / Tracking

นับวัตถุที่เคลื่อนที่ผ่านเส้น หรือ snapshot นับครั้งเดียว

🏭 Continuous Mode
1
ตั้ง ROI ให้ครอบพื้นที่ที่วัตถุผ่าน
2
ตั้ง Line Position ให้เส้นนับอยู่กลาง path
3
กด START — นับอัตโนมัติเมื่อวัตถุข้ามเส้น
📸 Stop & Capture Mode
1
วางวัตถุใน ROI
2
กด CAPTURE IMAGE — นับวัตถุใน frame นั้นทันที
3
บันทึกภาพ + metadata ไว้ใน captures/
🔧 Algorithm Parameters
ParameterDefaultRangeคำอธิบาย
Line Position (%Y) 50 5–95 ตำแหน่งเส้นนับแนวนอน (% จากบน) — ใช้กับ Continuous เท่านั้น
Min Area 1,000 100–20,000 ขนาดพิกเซลขั้นต่ำที่จะนับ
Threshold 100 0–255 ค่า threshold แยกวัตถุออกจากพื้นหลัง
Polarity Dark Object Dark / Light วัตถุสีเข้มกว่าพื้นหลัง (Dark) หรือสว่างกว่า (Light)
Adaptive Threshold ปิด on/off คำนวณ threshold อัตโนมัติตาม local area — ใช้เมื่อแสงไม่สม่ำเสมอ
⚠️ Parameters เหล่านี้ (Threshold, Polarity, Adaptive) เปิดใช้งานได้เฉพาะใน Counting/Tracking mode เท่านั้น — mode อื่นจะ disabled อัตโนมัติ
🎯 เมื่อไหร่ใช้ Polarity อะไร
⬛ Dark Object
วัตถุสีดำ/เข้ม บนพื้นหลังสว่าง
เช่น: กระดาษขาว, พื้นสว่าง
⬜ Light Object
วัตถุสีขาว/สว่าง บนพื้นหลังมืด
เช่น: สายพานดำ, พื้นมืด

Mode 5

Sticker Inspection

ตรวจสอบว่าสติ๊กเกอร์ติดถูกต้อง ไม่กลับหัว ไม่เอียง ไม่ฉีกขาด

🚀 วิธีใช้งาน
1
วาง ชิ้นงานที่มีสติ๊กเกอร์ถูกต้อง (reference) ใน ROI
2
กด CHANGE STICKER REFERENCE — ระบบบันทึกและจำรูปร่าง, ทิศทาง, ขนาด reference ไว้
3
วางชิ้นงานที่ต้องการตรวจ → กด CAPTURE IMAGE
4
กรอบ สีเขียว = PASS  |  กรอบ สีแดง = FAIL พร้อมบอกสาเหตุ
💾 Reference ถูกบันทึกไว้ที่ config/sticker_reference.png — จะถูก reload อัตโนมัติเมื่อเปิดโปรแกรมครั้งต่อไป
🔧 Algorithm Parameters
ParameterDefaultRangeคำอธิบาย
Match Threshold (%) 70 40–95 ความคล้ายสติ๊กเกอร์กับ reference ขั้นต่ำ — ลดถ้า false fail เยอะ
Min Area (px) 250 50–20,000 ขนาดพิกเซลขั้นต่ำของสติ๊กเกอร์ — เพิ่มถ้าระบบ detect noise สิ่งแวดล้อม
Max Angle Error (deg) 12 1–45 ยอมให้สติ๊กเกอร์เอียงได้กี่องศา — เพิ่มถ้า jig ไม่ fix ตำแหน่งแน่น
